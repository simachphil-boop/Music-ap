# Floya FM — музыкальный и видеоплеер для Android

Нативное офлайн-приложение для локальной музыки и видео: Kotlin, Jetpack Compose, Material 3 с собственной дизайн-системой, Media3/ExoPlayer, Room и DataStore. Регистрация и интернет не нужны, все данные хранятся только на устройстве.

## Возможности

**Музыка**
- Сканирование медиатеки устройства (MediaStore) и импорт файлов или целых папок через Storage Access Framework. Файлы не копируются: приложение хранит только URI с постоянным разрешением на чтение.
- Форматы: MP3, FLAC, M4A/AAC, OGG/OPUS, WAV, AMR, MKA и др. Неподдерживаемые и повреждённые файлы распознаются и пропускаются с понятным сообщением.
- Разделы: песни, альбомы, исполнители, жанры, избранное, недавно добавленные, история.
- Поиск и сортировка: по названию, исполнителю, дате добавления, длительности.
- Полноэкранный плеер:
  - обложка из тегов файла, фон, окрашенный в цвет обложки;
  - свайпы по обложке для переключения треков, перемотка;
  - shuffle и повтор (всё / один трек);
  - системная громкость, избранное с анимацией, добавление в плейлист.
- Очередь с перетаскиванием треков, кнопками «играть следующим» и «в очередь».
- Фоновое воспроизведение через `MediaSessionService`: уведомление, экран блокировки, кнопки Bluetooth- и проводных гарнитур, аудиофокус.
- Пауза при отключении наушников и (по желанию) продолжение при подключении.
- Таймер сна с плавным затуханием, вариант «до конца трека».
- Эквалайзер с пресетами устройства, усилением басов и объёмным звуком.
- Сведения о файле (битрейт, частота, разрядность) и редактирование названия, исполнителя, альбома и жанра в библиотеке приложения.
- Автоматическое сохранение и восстановление очереди и позиции после перезапуска.

**Волна**
- Бесконечный поток из вашей библиотеки: «Моя волна», настроения (Бодрое, Весёлое, Спокойное, Грустное, Мрачное), занятия (Тренировка, Фокус, Дорога, Вечеринка, Отдых, Сон) и характер (Любимое, Незнакомое, Забытое).
- Звучание каждого трека анализируется на устройстве: громкость, темп, яркость, динамика. Волна учится на избранном, пропусках и кнопке «Не нравится». Работает без интернета.

**Загрузка по ссылке** (нужен интернет)
- Видео или аудио (MP3 с обложкой) с YouTube, VK, Rutube, TikTok, SoundCloud и сотен других сайтов — через встроенный yt-dlp, а также прямые ссылки на файлы.
- «Поделиться → Floya FM» из любого приложения, выбор качества, прогресс в уведомлении, обновление движка из настроек.
- Файлы сохраняются в «Фильмы/Floya» и «Музыка/Floya» и сразу появляются в библиотеке. Скачивайте только то, на что у вас есть права.

**Видео**
- Отдельный видеоплеер:
  - жесты: двойной тап — ±10 с, вертикальный свайп слева — яркость, справа — громкость;
  - скорость 0.25×–2×, соотношение сторон (вписать, заполнить, растянуть, 16:9, 4:3, 21:9);
  - полноэкранный режим, поворот экрана, блокировка управления, «картинка в картинке».
- Продолжение с места остановки, разделы «Недавние» и «Избранное», видеоплейлисты.

**Плейлисты**
- Музыкальные и видеоплейлисты: создание, переименование, удаление.
- Своя обложка или автоматическая мозаика из первых обложек.
- Добавление и удаление элементов, порядок меняется перетаскиванием.

**Темы**
- Семь тем: Gothic Dark, Midnight, Cyberpunk, Minimal Light, Rose, Forest, AMOLED Black.
- Каждая тема задаёт палитру, шрифт заголовков, форму углов (у Cyberpunk — скошенные), орнамент и оформление плеера.
- Перед применением тему можно посмотреть на своей библиотеке. Смена анимирована, выбор сохраняется.
- Новая тема добавляется одним объектом `VesperTheme` в `ThemeRegistry.all` (`ui/theme/VesperThemes.kt`).

## Архитектура

```
app/src/main/java/app/vesper/player/
├── VesperApp.kt                 # Application + ручной DI-контейнер
├── MainActivity.kt              # Разрешения, SAF-пикеры, intent'ы, корень Compose
├── data/
│   ├── db/                      # Room: треки, видео, плейлисты, очередь
│   ├── prefs/                   # DataStore: настройки, тема, эквалайзер, позиция
│   ├── media/                   # MediaStore-сканер, SAF-импорт, загрузчик обложек
│   └── LibraryRepository.kt     # Единая точка доступа к библиотеке
├── playback/
│   ├── PlaybackService.kt       # MediaSessionService + ExoPlayer (фон, уведомление)
│   ├── PlayerConnection.kt      # MediaController для UI, очередь, shuffle
│   ├── AudioEffects.kt          # Equalizer / BassBoost / Virtualizer
│   └── SleepTimer.kt
├── ui/
│   ├── theme/                   # Дизайн-система и 7 тем
│   ├── components/              # Обложки, кнопки, слайдеры, шиты, строки
│   ├── player/                  # Mini player, полноэкранный плеер, очередь
│   ├── screens/                 # Главная, Музыка, Видео, Плейлисты, Настройки…
│   └── MainViewModel.kt         # MVVM: состояние библиотеки и действия
└── video/                       # VideoPlayerActivity + Compose-оверлей
```

## Сборка

Требования: JDK 17+ и Android SDK (платформа 35). Проще всего открыть проект в Android Studio Ladybug или новее.

```bash
# Debug-сборка
./gradlew assembleDebug
# → app/build/outputs/apk/debug/app-debug.apk

# Release-сборка (подписывается ключом из keystore/)
./gradlew assembleRelease
# → app/build/outputs/apk/release/app-arm64-v8a-release.apk (и armeabi-v7a)

# Установка на подключённый телефон
adb install -r app/build/outputs/apk/release/app-arm64-v8a-release.apk
```

Минимальная версия — Android 9 (API 28), target — API 35.

### Автоматическая сборка APK в GitHub

Workflow `.github/workflows/build.yml` при каждом push собирает подписанные release APK и публикует их на вкладке **Releases**. Скачайте `FloyaFM-N-arm64.apk` (большинство телефонов) или `FloyaFM-N-armv7.apk` (старые 32-битные) и установите на телефон (разрешите установку из неизвестных источников).

### Подпись

`keystore/vesper-release.jks` — ключ для частной установки (пароль `vesperplayer`, alias `vesper`). Перед публикацией в Google Play создайте собственный ключ и уберите пароли из `app/build.gradle.kts` (например, в `local.properties` или секреты CI).

## Шрифты

В `res/font` лежат шрифты из Google Fonts под лицензией SIL Open Font License: Manrope, Cormorant Garamond, Chakra Petch, DM Serif Display. Они упакованы в APK и работают без сети.
